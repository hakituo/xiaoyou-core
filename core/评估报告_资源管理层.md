## 一、概述

资源管理层（Resource Management Layer）是Xiaoyou-Core系统的核心资源管理基础设施，负责统一管理系统资源（内存、CPU、GPU、磁盘）。该层采用单例模式和观察者模式，实现了智能的资源监控、模型管理和自动优化。

> **架构变更说明**：资源管理层已于 2026-05-29 由单体文件 `core/resource_manager.py`（1728 行）重构为 `core/resource/` 模块化结构（含 6 个子模块），原文件保留为兼容层。下文评估已同步反映新结构。

#### 模块结构（2026-05-29 重构后）
```
core/resource/
├── __init__.py          # 模块入口，导出所有公共接口
├── config.py            # 配置管理（ResourceConfig 数据类）
├── monitor.py           # 资源监控 + GPU 缓存优化（0.5 秒 TTL）
├── model_manager.py     # 模型生命周期管理
├── cleanup.py           # 清理策略（策略模式，支持动态冷却时间）
├── gpu.py               # GPU 显存管理和模型卸载/加载
└── manager.py           # 主管理器，整合所有子模块
```

> `core/resource_manager.py` 现仅为兼容层，保留旧导入路径（`from core.resource_manager import ...`）的向后兼容性，实际逻辑全部迁移至 `core/resource/` 子模块。

#### 功能特性
- **资源监控** (`monitor.py`):
  - 实时内存/CPU/GPU监控
  - 多级阈值（警告、临界、紧急）
  - NVML和nvidia-smi双检测
  - GPU 内存查询缓存（0.5 秒 TTL，减少 nvidia-smi 调用）
- **模型管理** (`model_manager.py`):
  - 模型注册/卸载
  - 设备判定（GPU/CPU）
  - VRAM占用估算
  - 优先级管理
  - 并行卸载/加载
- **自动优化** (`cleanup.py` + `gpu.py`):
  - 三级清理模式（常规、临界、紧急）
  - 模型超时卸载
  - 缓存清理
  - GPU模型自动回迁
  - 支持动态冷却时间
- **GPU 显存管理** (`gpu.py`):
  - GPU 显存查询与估算
  - 模型卸载/加载执行
  - GPU/CPU 热切换
- **配置管理** (`config.py`):
  - ResourceConfig 数据类集中管理配置
  - 阈值、超时、缓存 TTL 等参数统一管理
- **资源处理器**:
  - 注册资源处理器
  - 按优先级释放资源
- **重负载任务准备** (`manager.py`):
  - 为LLM/图像生成/视觉任务准备资源
  - 并行卸载冲突模型
  - 显存充足时跳过激进清理

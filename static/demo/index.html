异构资源隔离架构

  • 硬件抽象层 (HAL): C++ 编写的调度引擎，屏蔽了 CPU/GPU/NPU 的底层差异。
  • 弹性负载均衡: 根据当前显存水位，动态决定模型加载策略（n_gpu_layers）。
  • 并发互斥锁: GlobalResourceLock 确保生图与语音合成不发生硬件级冲突。

8GB 显存极限优化

  • Dynamic Offloading: 当显存压力 > 90% 时，自动将非核心模型 Offload 至 Host RAM。
  • 梯度降级加载: 启动时自动探测可用显存，按 64->48->32 步进调整显存占用。
  • 零开销上下文切换: 利用 C++ 指针保留实例，仅迁移权重张量，实现秒级热启动。
